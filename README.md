# Amir-Kabir Dam HAB reproducibility repository

This repository contains code and data used in the manuscript:
"Modeling Meteorological Impacts on Water Quality and Algal Dynamics in Amir Kabir Dam."

## Structure
- /code – R scripts for GAM, Random Forest, SEM, and Prophet
- /data – anonymized input data for reproduction
- /results – (optional) example model outputs or figures

## Software
R version 4.3.x
Packages: mgcv, randomForest, forecast/prophet, lavaan

## How to reproduce
1. Open /code/GAM_RandomForest.R
2. Load the CSV files from /data
3. Run the GAM and RF models
4. Compare results with Table 2 and Figures 2–4 in the manuscript
